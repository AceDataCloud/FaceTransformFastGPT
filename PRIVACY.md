# Privacy

This plugin runs inside the FastGPT Plugin service. It sends an authorized image URL, chosen action and settings, and the application API key over HTTPS to api.acedata.cloud. It has no separate telemetry endpoint or persistent storage.

Only use portraits for which you have appropriate rights and consent. Face and liveness outputs must not be treated as identity proof without other checks. FastGPT stores the key through its plugin secret configuration. Do not put keys in prompts, exports, screenshots, or support requests. Request records follow the [Ace Data Cloud privacy terms](https://platform.acedata.cloud/privacy).
